# Bằng chứng kiểm chứng Phase 1–3

Chạy `node tools/verify.js`. Lệnh ghi JSON đầu ra thật vào `phase-1-3-verification.json`, gồm phiên bản Node và thời gian mô phỏng Đêm 3 đầy đủ (18.000 tick). Suite kiểm tra regression các phase trước và scenario mới cho relight, top-up, fuel-out, shade drain, pulse khi drain, capacity và điều kiện thắng/điểm ở bình minh.

Kết quả chỉ chứng minh các mục được suite liệt kê. Chưa có test ẩn, kiểm thử trực quan trình duyệt, đo FPS giao diện, video, tag hoặc Release.
